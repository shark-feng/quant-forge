# 风险与合规声明（RISK DISCLAIMER）

## 1. 用途限定

本系统（A 股量化研究系统，代号 `aqs`）**仅用于量化研究与教学**：

- 不构成任何投资建议、收益承诺或投资顾问服务；
- 不提供任何形式的证券买卖通道；
- 不接入真实券商交易接口，不下发真实资金指令。

## 2. 阶段限定

| 阶段 | 内容 | 限制 |
|---|---|---|
| 第一阶段 | 日频事件驱动回测 | 研究用途 |
| 第二阶段 | 多因子、统计套利 | 研究用途 |
| 第三阶段 | Tick/订单簿回放、最优执行、蒙特卡洛 | **仅模拟**，输出必须标注 `research_only=True` |

**明确不做**：高频做市、延迟套利、跨市场实盘套利、裸卖空、期权做市，以及任何 A 股无法合规落地的功能。

## 3. 回测固有局限（必须随报告一并展示）

1. **数据局限**：复权方式、停牌处理、退市股票、指数成分变更、财务公告日，任一处理不当都会显著高估收益。
2. **撮合局限**：日频撮合无法反映盘口深度、排队位置与部分成交的真实分布；涨跌停“买不进/卖不出”为近似建模。
3. **成本局限**：佣金/印花税/过户费随券商与政策变化；冲击成本参数（η、θ）为经验估计。
4. **容量局限**：策略容量受流动性约束，规模放大后收益衰减甚至转负。
5. **过拟合风险**：参数寻优、样本内表现优异均不代表未来有效。
6. **幸存者偏差**：本系统已内置退市股票与历史指数成分，但数据源本身若缺失退市股仍会污染结果。
